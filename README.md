# Anw Kalan — application mobile

**Page de telechargement : https://bahdev223.github.io/anwkalan-app/**

C'est cette adresse qu'il faut partager : elle affiche le logo et une
description quand on la colle dans WhatsApp, Facebook ou Messenger. Le lien
direct vers le fichier `.apk` n'affiche rien du tout — les moteurs d'apercu
ne lisent pas les binaires.

## Telechargement direct

https://github.com/bahdev223/anwkalan-app/releases/latest/download/anwkalan.apk

## Installation

1. Telecharger le fichier `anwkalan.apk`.
2. Android demandera d'autoriser l'installation depuis cette source : accepter.
3. Ouvrir le fichier telecharge.

Android 7.0 minimum, environ 36 Mo, processeurs ARM.

Ce depot ne sert qu'a la distribution. Le code source vit ailleurs.
