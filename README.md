# Anw Kalan — application mobile

Telecharge la derniere version depuis la page **[Releases](../../releases/latest)**.

## Installation

1. Telecharge le fichier `anwkalan.apk`.
2. Android demandera d'autoriser l'installation depuis cette source : accepte.
3. Ouvre le fichier telecharge.

Android 7.0 minimum, environ 36 Mo, processeurs ARM.

Ce depot ne sert qu'a la distribution. Le code source vit ailleurs.
